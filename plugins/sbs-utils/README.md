# sbs-utils

Everyday utilities for raffles and Slack emoji.

See the [marketplace README](../../README.md) for installation, updates, and removal.

## Skills

| Skill | Description |
| --- | --- |
| [raffle](skills/raffle/SKILL.md) | Randomly select a unique winner from a CSV roster, record the result, and announce a masked email address. |
| [slack-emoji-optimizer](skills/slack-emoji-optimizer/SKILL.md) | Convert animated WebP images into Slack custom emoji GIFs while preserving animation and transparency. |
